# Reference Material

Use this folder for historical material supplied to help study the original game, such as emulator files, cassette inlay scans, manuals, screenshots, notes, and gameplay footage.

For each item, record if known:

- filename;
- source or owner;
- date received;
- what it demonstrates;
- whether it may be redistributed.

Reference material is for analysis. Do not include it in public builds or copy its protected assets into the new game without confirmed permission.
